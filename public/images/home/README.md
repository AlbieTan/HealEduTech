# Homepage photography

These genuine photographs support the topic story cards. The previous bookshelf hero photo remains archived in this folder and is unused by the current hero, which uses the locally served Storyset illustration documented below. The files are served locally, with 800, 1600 and 2400 pixel WebP variants for phones, desktop and retina displays. Topic photos load lazily. CSS supplies the gradients so text remains selectable and translated.
